Mengapa Relay?

Fitur Utama

Token Auth

Setiap proyek memiliki token unik X-Relay-Token. Hanya agent dengan token yang cocok yang bisa menerima data.

Queue berbasis Redis

Webhook tidak terlewat. Pesan masuk antri di Redis dan langsung dikirim ke agent yang sedang aktif.

WebSocket Real-time

Relay Agent terhubung via WebSocket. Webhook diteruskan hampir seketika tanpa polling.

Multi-proyek

Kelola banyak proyek dalam satu akun. Masing-masing proyek punya endpoint dan token sendiri.

Agent ringan

Relay Agent adalah binary tunggal tanpa dependensi. Jalankan dengan satu perintah di Windows, macOS, atau Linux.

Konfigurasi fleksibel

Atur URL tujuan lokal, aktifkan/nonaktifkan proyek, dan pantau status agent langsung dari dashboard.

Panduan Cepat

Cara Menggunakan Relay

Dari daftar hingga webhook diterima di localhost, hanya butuh 5 menit.

1

Buat Akun & Proyek

Daftar di relay.duls.space/register, lalu masuk ke Dashboard → Buat Proyek Baru. Isi nama proyek dan aktifkan status.

Setelah proyek dibuat, Anda akan mendapat Project ID dan Public URL. Keduanya dibutuhkan saat setup wizard agent.

2

Install & Jalankan Relay Agent

Download binary sesuai OS Anda — tidak perlu install apapun. Wizard interaktif akan muncul otomatis saat pertama kali dijalankan.

# 1. Download binary (pilih sesuai chip)
# Apple Silicon — M1/M2/M3/M4
curl -L "https://github.com/theKims0/relay-agent/releases/latest/download/relay-agent-darwin-arm64" -o relay-agent

# Intel Mac
curl -L "https://github.com/theKims0/relay-agent/releases/latest/download/relay-agent-darwin-amd64" -o relay-agent

# 2. Beri izin eksekusi
chmod +x relay-agent

# 3. Jalankan — wizard otomatis akan muncul saat pertama kali
./relay-agent
# 1. Download binary
# x86_64 (server biasa / VPS)
curl -L "https://github.com/theKims0/relay-agent/releases/latest/download/relay-agent-linux-amd64" -o relay-agent

# ARM64 (Raspberry Pi / Oracle ARM)
curl -L "https://github.com/theKims0/relay-agent/releases/latest/download/relay-agent-linux-arm64" -o relay-agent

# 2. Beri izin eksekusi
chmod +x relay-agent

# 3. Jalankan — wizard otomatis akan muncul saat pertama kali
./relay-agent
# PowerShell
# 1. Download binary
Invoke-WebRequest -Uri "https://github.com/theKims0/relay-agent/releases/latest/download/relay-agent-windows-amd64.exe" -OutFile "relay-agent.exe"

# 2. Jalankan — wizard otomatis akan muncul saat pertama kali
.\relay-agent.exe

💡 Saat pertama kali dijalankan, wizard akan muncul:

╔══════════════════════════════════════════════════╗
║          Relay Agent — First Time Setup          ║
╚══════════════════════════════════════════════════╝

  Project ID  (dari dashboard Relay): <YOUR_PROJECT_ID>
  Server URL  [ws://localhost:8081] : wss://relay.duls.space/ws/agent
  Target URL  (service lokal Anda) : http://localhost:3000

  ✅ Konfigurasi disimpan ke relay.json

Jalankan berikutnya langsung konek tanpa wizard. Reset dengan --reset.

Setelah terhubung, agent siap menerima dan meneruskan webhook ke service lokal Anda.

3

Daftarkan Webhook URL ke Layanan Eksternal

Gunakan Public URL proyek Anda sebagai endpoint webhook di layanan seperti GitHub, Stripe, Midtrans, dll.

Format Endpoint

https://relay.duls.space/v1/gateway/{public-url-slug}

Ganti {public-url-slug} dengan slug proyek Anda dari dashboard.

Contoh — GitHub Webhook

# Settings → Webhooks → Add webhook
Payload URL : https://relay.duls.space/v1/gateway/payment-relay
Content type: application/json
Secret      : (kosongkan atau isi bebas)
Events      : Just the push event (atau pilih sesuai kebutuhan)

Test manual dengan cURL

curl -X POST https://relay.duls.space/v1/gateway/payment-relay \
     -H "Content-Type: application/json" \
     -d '{"event":"payment.success","amount":150000}'
4

Terima Webhook di Lokal

Agent akan meneruskan request masuk ke URL target lokal Anda. Pastikan server lokal sedang berjalan.

Contoh — Express.js

// server.js
const express = require('express');
const app = express();
app.use(express.json());

app.post('/webhook', (req, res) => {
    console.log('Webhook diterima:', req.body);
    res.json({ status: 'ok' });
});

app.listen(3000, () =>
    console.log('Server jalan di port 3000'));

Jalankan: node server.js — lalu agent akan meneruskan webhook ke http://localhost:3000/webhook
